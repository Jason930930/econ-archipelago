# 情境推演 — 設計規格（總體金融數位孿生・子專案 4）

- 日期：2026-11-07
- 狀態：使用者已核可設計（推演引擎 A、三波動畫、與目前狀態對照），並指示一路實作到底
- 前置：常駐傳導網絡（子專案 2）、完整狀態鏡像（子專案 3）
- 分支：`feat/what-if`

## 1. 目標與成功標準

使用者選一個節點、給一個方向的衝擊（例：「油價 ↑」），網站沿著常駐傳導網絡推演衝擊會擴散到哪些節點：方向、強弱、大約多久、為什麼（主要路徑），並和該週的節點狀態對照。重點是學習傳導邏輯，尤其最後如何影響台灣。全部是定性推演，不是預測。

成功標準：
1. 36 個節點都可以當衝擊起點，上升或下降皆可；同樣的輸入永遠得到同樣的結果。
2. 每個受影響的節點顯示方向（或「方向分歧」）、強弱（強／中／弱）、時間（數日／數週／數月）、主要路徑，以及與目前狀態的對照。
3. 3D 世界依數日 → 數週 → 數月三波播放：管線上的光點、節點上的「預估」標記。
4. 結果面板把「對台灣」放在最前面；推演可以從頂欄或狀態卡開始，有可分享的網址，文字模式也能用。
5. v1～子專案 3 的功能與測試都不退化。

非目標：多個同時衝擊、衝擊幅度（例：+20%）、量化係數或數值預測、儲存情境、在網頁上編輯管道。

## 2. 推演引擎（`src/world/scenario.ts`，純邏輯）

```ts
interface Shock { node: string; direction: 1 | -1 }
type Strength = 'strong' | 'medium' | 'weak';
type Wave = 1 | 2 | 3;            // 1 數日、2 數週、3 數月
interface Effect {
  node: string;
  direction: 1 | -1 | null;       // null = 方向分歧
  weight: number;                  // 主要路徑的權重（0–1）
  strength: Strength;
  wave: Wave;
  path: string[];                  // 主要路徑的管道 id（依序）
  counterPath?: string[];          // 方向分歧時，方向相反的最強路徑
  vsCurrent: 'same' | 'opposite' | 'none';
  extreme?: 'high' | 'low';
}
interface ScenarioResult { shock: Shock; effects: Effect[]; taiwan: Effect[] }
```

- **路徑列舉**：從衝擊節點出發，沿 `CHANNELS`（from → to，節點 id）做深度優先搜尋，最多 4 跳，路徑不可重複經過任何節點（含起點）。
- **路徑方向** = 衝擊方向 × 路徑上每條管道的 `sign`。
- **路徑權重** = Π(管道 `strength` ÷ 3) × 0.7^(跳數 − 1)。
- **每個節點**：
  - 主要路徑 = 權重最大者；平手時跳數少者優先，再依管道 id 串接字串的字典序。
  - 方向相反的路徑中最強者，權重 ≥ 主要路徑 × 0.5 → `direction: null`（方向分歧），並記錄 `counterPath`。
  - 強弱：權重 ≥ 0.5 強、≥ 0.2 中、≥ 0.05 弱；< 0.05 不列入結果。
  - 時間：主要路徑上最慢的 `lag`（days → 1、weeks → 2、months → 3）。
- **與目前狀態對照**（呼叫端傳入該週的 `Record<nodeId, NodeState>`）：
  - 有方向的結果，節點目前方向為 ±1：同向 → `same`、反向 → `opposite`；目前方向為 0、null 或未知 → `none`；方向分歧 → `none`。
  - 結果 ↑ 且節點目前水準 `high` → `extreme: 'high'`；結果 ↓ 且水準 `low` → `extreme: 'low'`。
- **排序**：依 wave 升冪，再依 weight 降冪，再依節點在 `CHANNEL_NODES` 的順序。
- **台灣**：`taiwan` = effects 中節點路徑在 `tw` 之下或為 `seas/shipping-lane/taiwan-strait` 者（保持相同順序）。
- **API**：`runScenario(shock: Shock, states: Record<string, NodeState>): ScenarioResult`；`STRENGTH_TEXT = { strong: '強', medium: '中', weak: '弱' }`、`WAVE_TEXT = { 1: '數日', 2: '數週', 3: '數月' }`。
- 衝擊節點不存在 → 丟錯（網址解析在呼叫前就會擋下）。

固定說明（面板與文字模式）：「依教科書層級的定性傳導關係推演，不是預測。」

## 3. 互動

- **頂欄「情境推演」按鈕**（`data-action="what-if"`）：開啟挑選面板，依地區分組列出 36 個節點；選一個節點後選「上升 ↑」或「下降 ↓」，按「推演」。
- **狀態卡**加兩個按鈕「推演：若上升」「推演：若下降」（事件 `start-scenario`，detail `{ node, direction }`）。
- 推演中：播放暫停；3D 世界播放三波；面板換成結果。切換週次時保留情境，依新週狀態重算對照。隨時可以換一個衝擊（取代目前的）。「結束推演」或 Esc 清除並回到一般畫面。
- **網址**：`#/<weekId>/what-if/<nodeId>/<up|down>`。無效的節點或方向 → toast 提示並回到該週一般畫面（`invalid: true`）。
- **文字模式**：「情境推演」按鈕同樣可用；結果以文字列在文字頁面最上方（衝擊、對台灣、數日／數週／數月三段，每列含方向、強弱、對照與「為什麼」），沒有動畫。

## 4. 3D 顯示（`src/render/layers/scenario.ts`）

- `WorldView.showScenario(result: ScenarioResult | null): Promise<void>`：`null` 清除。開始時把鏡頭拉回全圖（手機為亞太）。
- 衝擊節點：脈動光環＋大箭頭標記。
- 管線聚焦：結果路徑上的管道維持亮管、其他管道淡到暗管以下（`ChannelLayer.setFocus(ids: Set<string> | null)`）。
- 三波：第 k 波時，把「wave = k 的結果主要路徑上、尚未播放過的管道」同時播放光點（不顯示文字標籤、粒子數減少），畫面上方顯示「數日／數週／數月」橫幅；該波結束時，這些節點出現「預估」標記：虛線框膠囊，內容為箭頭＋強弱（方向分歧為「⇅」），中性色，不用紅綠。每波約 1.6 秒（受播放速度與 `?fast=1` 影響）。
- 推演中隱藏節點狀態徽章，結束後恢復；`clear()`／週次切換時會清除推演動畫但保留標記直到 `showScenario(null)`。
- 「重播」重新執行同一個 `showScenario(result)`。

## 5. UI（`src/ui/scenarioPanel.ts`）

- `renderScenarioPicker(states, index)`：依地區分組的 36 個節點（顯示目前狀態小標），選中後出現「上升 ↑」「下降 ↓」與「推演」按鈕；事件 `start-scenario`。
- `renderScenarioResult(result, index)`：
  - 標題「情境：油價 ↑」與固定說明；
  - 「對台灣」區塊（沒有結果時顯示「這個衝擊沒有傳到台灣的節點」）；
  - 「數日」「數週」「數月」三段；每列：節點名稱、方向箭頭（或「方向分歧 ⇅」）、強弱小標、對照文字（「與目前趨勢一致（加劇）」「與目前趨勢相反（可能反轉）」）、極值註記（「已在 5 年高檔」「已在 5 年低檔」）、「為什麼」：`油價 ↑ → 美國通膨 ↑ → Fed 政策利率 ↑`（每一步的方向依路徑推算；滑過顯示該管道的機制）；方向分歧時列出兩條路徑。
  - 沒有任何結果 →「這個節點目前沒有可往外傳導的管道」。
  - 按鈕：「重播」（事件 `replay-scenario`）、「結束推演」（事件 `end-scenario`）；點一列 = 飛到該節點（`select-node`，不結束推演）。
- `renderScenarioText(result, index)`：文字模式版本（`.text-scenario`）。
- 所有文字都是常數或節點、管道名稱，仍一律以 textContent 寫入。

## 6. 測試

- **單元**：
  - 引擎：路徑方向相乘、權重公式與衰減、4 跳上限、不重複經過節點、平手規則、方向分歧門檻、< 0.05 剔除、wave 取最慢 lag、對照與極值、台灣清單、沒有出邊的節點回傳空結果、36 個節點 × 2 方向全部可執行且結果穩定（同輸入兩次結果相同）。
  - 範例情境：油價 ↑ → 美國通膨 ↑（強、數週）出現在結果中；美債殖利率 ↑ → 美國科技股估值 ↓。
  - 網址解析：`what-if` 路徑、無效節點與方向。
  - UI（jsdom）：挑選面板 36 列、結果面板（台灣區塊、三段、為什麼路徑、方向分歧兩條路徑、空結果訊息）、文字模式段落、狀態卡的兩個推演按鈕。
- **E2E**：頂欄開始推演 → 結果面板與預估標記出現；狀態卡按鈕開始推演；分享網址直接開出推演；Esc 結束後標記消失、徽章恢復；文字模式列出推演結果。

## 7. 留給後續的介面

- `runScenario` 可擴充為多個衝擊（把多個起點的路徑一起列舉）。
- 推演結果的 `direction` 可以在下一週和實際狀態對照（「本週延伸與檢驗」，未來子專案）。
