# 情境推演 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 從任一節點給一個方向的衝擊，沿傳導網絡推演影響（方向、強弱、時間、路徑、與目前狀態對照），以三波動畫與結果面板呈現。

**Architecture:** 純邏輯引擎 `src/world/scenario.ts` 列舉路徑並彙總；`src/ui/route.ts` 解析分享網址；`src/render/layers/scenario.ts` 播放三波與預估標記；`src/ui/scenarioPanel.ts` 呈現挑選與結果；`app.ts` 串起來。

**Tech Stack:** TypeScript、Three.js（CSS2D 標記、既有管線層）、Vitest（jsdom）、Playwright。

**Spec:** `docs/superpowers/specs/2026-11-07-what-if-design.md`

## Global Constraints

- 最多 4 跳；權重 Π(strength/3) × 0.7^(跳數−1)；強 ≥ 0.5、中 ≥ 0.2、弱 ≥ 0.05，< 0.05 剔除；方向分歧門檻 0.5。
- wave：days 1、weeks 2、months 3（主要路徑上最慢者）。
- 固定說明原文：「依教科書層級的定性傳導關係推演，不是預測。」
- 網址：`#/<weekId>/what-if/<nodeId>/<up|down>`。
- 預估標記不用紅綠；推演中隱藏狀態徽章。
- 建置與測試不連網；所有文字以 textContent 寫入；提交訊息結尾附 Co-Authored-By 與 Claude-Session 兩行。

## Review Focus

1. **衝擊節點沒有出邊**（例：`tw.equity`）→ 空結果與提示文字，不報錯（Task 1 測試 `sink node gives empty result`、Task 4 測試 `empty result message`）。
2. **網路有環**（例：美股 → 風險偏好 → …）→ 路徑不重複經過節點、不會無限遞迴（Task 1 測試 `paths never revisit a node`）。
3. **分享網址的節點或方向無效** → 回到該週一般畫面並提示（Task 2 測試 `invalid what-if hash`）。
4. **推演中切換週次** → 情境保留、對照依新週重算（Task 5 E2E `scenario survives week change`）。
5. **推演中按播放或點事件** → 先結束推演再播放，不會留下標記（Task 5 E2E `play ends the scenario`）。
