# 長期資料成長 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 時間軸只顯示視窗內的週（可翻頁、年月標籤、主線過濾），索引把每週衍生資料分成每週一個檔案按需載入，發佈的 JSON 壓縮。

**Architecture:** `buildIndex` 照舊產生完整索引；新的純函式 `splitIndex`／`hydrateWeek` 在建置時分拆、在前端載入某週時填回，讓既有讀 `byWeek` 的程式不必改。時間軸以純函式 `timelineWindow` 決定視窗。

**Tech Stack:** TypeScript、Vitest（jsdom）、Playwright。

**Spec:** `docs/superpowers/specs/2026-11-07-scale-design.md`

## Global Constraints

- 視窗大小：桌機 12、窄螢幕（≤ 767 px）6；翻頁一次移動 `max(1, floor(size / 2))`。
- `public/data/index.json` 與 `public/data/derived/*.json` 為單行壓縮 JSON；`data/index.json` 為縮排 catalog。
- 不引入外部資料庫；建置與測試不連網；排程與說明書不修改。
- 提交訊息結尾附 Co-Authored-By 與 Claude-Session 兩行。

## Review Focus

1. **derived 檔案抓不到**（404、網路錯誤）→ 該週視為載入失敗並提示，不以缺資料渲染（Task 2 E2E `derived failure shows the load error`）。
2. **快速連續切週**，較慢的 derived 晚回來 → 只採用最後一次導覽（Task 2，沿用 navSeq；E2E `derived requested for each visited week`）。
3. **只有 1–3 週資料**（少於視窗大小）→ 視窗從第一週開始，翻頁按鈕都停用（Task 3 測試 `fewer weeks than the window`）。
4. **從分享網址或管道歷史跳到視窗外的週** → 視窗自動移到包含那一週（Task 3 測試 `current outside the window moves the window`）。
5. **高亮中的主線在視窗內沒有事件** → 仍保留那一列，可以取消高亮（Task 3 測試 `highlighted storyline stays visible`）。
